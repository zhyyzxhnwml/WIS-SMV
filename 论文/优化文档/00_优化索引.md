## 四轮优化一句话总结

| 轮次 | 做了什么 | 结果 |
|---|---|---|
| **O1 门控判据** | 把「送不送大模型」的判据从**模型风险分**换成**规则层证据强度** | ✅ **成功**：三个场景全部同时赢成本与质量（完整规则下 **100% F1 @ 27.1% 调用**，现役是 64.3% @ 100%） |
| **O3 真实数据成本** | 把新门控放到真实数据上量调用率 | ✅ **成本降到约 36%**（**6.2%** vs 旧门控 16.6% / 17.3%） |
| **O5 几何喂给大模型** | 把会遇几何算好写进提示（臂 H） | ⚠️ 召回全场最高 **97.5%**、提示最省，但精确率 51.3% → **退化成平凡分类器** |
| **O6 判据写成提示** | 把判定过程写清交给大模型执行（臂 I） | ⚠️ F1 **70.6%**；**同一条规则用代码执行是 100%、0 token** |

**最有价值的一条结论**：规则层的价值不只是「知道规则」，更是「**可靠地执行规则**」以及「**零成本**」。

## 最终结论：分域使用

```
规则覆盖良好的域（L1 精确率 100%）
    → 用证据强度判据：几乎免费拿到最优质量（100% @ 27.1% 调用）

规则覆盖差的域（L1 报掉 91% 的船）
    → 「无候选事件」不再是「规则盲区」，而是「安静的船」
    → 新判据不能单独使用，必须与风险分门控组合；组合阈值按域标定（尚未标定）
```

**新门控不是无条件更好，而是「在规则覆盖良好的域更好」**——这个前提必须在论文里写明。
