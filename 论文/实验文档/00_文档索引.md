## 一页纸速览：三条结论

| 结论 | 关键数字 | 详见 |
|---|---|---|
| **违规判断我们完胜** | 我们 100% F1；8 个文献方法 oracle F1 ≤ 77.9%，其中 7 个恰为 66.7% 的平凡线（AUC 低于随机）。F1 差 +22~+33 pt，p < 1e-20 | 文档 4 §2 |
| **级联在成本-质量上支配纯大模型** | 0 次调用 → 100% F1；240 次调用、120 万 token → 64.3%。纯大模型三个方案全部低于平凡线 | 文档 4 §3 |
| **级联的后两级有独立价值** | 把规则摘掉后 L1 召回 0%，大模型仍能捞回 100% / 20.8% | 文档 4 §5 |

## 必须如实交代的限制

1. **现役门控阈值跨域失效**：`RISK_GATE_THRESHOLD = 0.000880` 在注入集上的放行率是 100%，当前一次大模型调用都没省。该阈值是在别的数据集上标定的，论文里应写成「门控阈值必须按目标域重标定」。

**唯一的已知缺口**：未做双人人工标注 + κ 一致性检验（见文档 1 §5、文档 5 §10）。

## 专业术语查询表

五份文档中共涉及以下术语，按首次出现的文档归类。**每份文档开头都有该文档用到的术语解释**，此处为全局速查。

| 术语 | 一句话解释 | 详见 |
|---|---|---|
| 真值 / Ground Truth | 标准答案，必须独立于被测系统 | 文档 1 |
| 循环论证 | 拿系统自己的输出当答案，结论无效 | 文档 1 |
| 级联 / Cascade | 多级接力：便宜的层先过滤，疑难的才交给人/大模型 | 文档 1 |
| 基线 / Baseline | 对照组，必须是与已发表方法在同一条件下的对比 | 文档 1 |
| 注入 / 合成场景 | 用程序造出参数已知的违规场景，以获得条款级真值 | 文档 1 |
| 精确率 / 召回 / F1 | 别冤枉人 / 别漏掉 / 两者的调和平均 | 文档 1 |
| AUC | 排序能力；0.5 = 瞎猜，小于 0.5 = 方向反了 | 文档 1 |
| oracle 阈值 | 允许在测试集上调到最优，是上界（对对手最有利） | 文档 1 |
| @1%FPR 召回 | 在「每 100 条正常最多误报 1 条」这个诚实工作点上的召回 | 文档 1 |
| 帕累托支配 | 各项指标都不差、至少一项更好 | 文档 1 |
| 消融 / Ablation | 拆零件看分数掉多少，证明该零件有用 | 文档 1 |
| 显著性检验 | 判断差距是真实的还是运气 | 文档 1 |
| token | 大模型处理文本的最小单位，等于「油费」 | 文档 1 |
| 缓存指纹 | 给输入与代码算身份证号，对不上就重建 | 文档 2 |
| 上下文长度 num_ctx | 大模型一次最多看多少 token，超了会静默截断 | 文档 2 |

## 后续优化文档

主线实验跑完后，针对**实验暴露的最弱环节**（L2 门控没有排序能力、门控在注入集上一次调用都没省）做了定向优化，另成一套文档：

| 文档 | 内容 |
|---|---|
| [01_优化目的](../优化文档/01_优化目的.md) | 为什么要优化、两个可量化目标 |
| [02_优化设计](../优化文档/02_优化设计.md) | 判据定义、策略空间、零额外成本复现方法、退路设计 |
| [03_优化结果](../优化文档/03_优化结果.md) | 门控优化、真实数据调用成本、大模型那一级的两轮结果 |
| [04_优化验证](../优化文档/04_优化验证.md) | 九项验证 + 两项未验证项 |

**与本套文档的关系**：本套（实验文档）是**测量**已有系统，优化文档是**改进**它。

**优化结论一句话**：把门控判据从「模型风险分」换成「规则层证据强度」后，完整规则场景下从 **64.3% F1 @ 100% 调用** 变成 **100% F1 @ 27.1% 调用**；真实数据上调用率 **6.2%**（成本降至旧门控约 36%）。但这个优势**只在规则覆盖良好的域成立**（真实数据上 L1 报掉 91% 的船，新判据在规则覆盖差的域不能单独使用）。
