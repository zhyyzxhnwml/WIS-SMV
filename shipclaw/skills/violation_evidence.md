# 违规证据链 操作手册

## 触发条件
当用户询问"某艘船（MMSI）怎么违规的 / 为什么违规 / 违规依据 / 证据链"时使用本技能。
用户未提供 MMSI 号时，请提示用户提供 MMSI 号（6~9 位数字）。

## 操作步骤
1. 从用户消息中提取 MMSI 号（6~9 位数字）
2. 按 MMSI 查询该船最近一次的检测记录
3. 将查询结果整理为四段证据链：① 轨迹分析 → ② 规则匹配 → ③ 法规引用 → ④ LLM 复核

## 输出规范
- 必须按 ① 轨迹分析 → ② 规则匹配 → ③ 法规引用 → ④ LLM 复核 的顺序组织
- 轨迹分析：说明事件类型、所在区域、时间范围、证据点数量、平均/最高航速
- 规则匹配：说明命中的违规类型与规则来源（regulations.json，如限速/禁渔期/禁入）
- 法规引用：完整引用法规名称与条号（如《渔港水域交通安全管理条例》第10条）
- LLM 复核：给出最终评估与建议处置
- 未检出违规的船舶：说明 ML 路由分类、置信度与数据质量即可，不要虚构违规
- 用自然语言表达，让用户看懂"这艘船为什么违规、依据是什么"

## 禁止事项
- 禁止编造证据链或法规引用，一切以查询结果为准
- 查询结果中没有的信息（如具体法条、罚则）不得臆造
- 不要暴露内部字段名（detailed_result / regulation_ref 等），用自然语言表达
- 超出本技能范围的问题（如查询法规条文本身），引导使用"海事法规查询"技能
