# 我的数据概况 操作手册

## 操作步骤
1. 汇总辖区：船舶数、检测记录数、AIS 数据点数、违规起数。
2. 基于这几个数字给出一段简明的辖区状态解读。

## 输出规范
- 先用一句话给结论（辖区整体态势：船舶规模、活跃度、违规情况）。
- 数字来自查询结果，用千分位等易读格式呈现大数字。
- 违规起数 > 0 时，提示可进一步查看「我的违规记录」；数据规模大时提示可用「趋势分析」深入。
- 只解读查询结果里有的维度，缺失维度不猜测。

## 禁止事项
- ❌ 禁止编造船舶数、记录数、AIS 数据量、违规数。
- ❌ 禁止与其它用户/辖区数据做比较（数据仅限当前用户范围）。
- ❌ 禁止暴露 SQL 聚合逻辑。
