# 违规趋势分析 操作手册

## 操作步骤
1. 汇总辖区整体：扫描船舶数、检测记录数、违规起数。
2. 违规类型分布（按起数降序）。
3. 风险等级分布。
4. 多次违规船（惯犯）Top3。

## 输出规范
- 先给整体结论（共多少船、多少记录、多少违规、违规率如何）。
- 分布用「类型(起数)」紧凑呈现，惯犯点名列出。
- 在数据基础上做简短规律解读（哪类违规最多、哪条船反复违规），但**解读不得超出数据**。
- 全部数字来自查询结果，缺失的维度不编。

## 禁止事项
- ❌ 禁止编造统计数字、分布、惯犯名单。
- ❌ 禁止做与数据无关的推测或假设。
- ❌ 禁止暴露 SQL 聚合逻辑。
