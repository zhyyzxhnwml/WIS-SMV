# 数据库设计方案
## AIS船舶违规检测系统 — PostgreSQL + pgvector

> **文档状态：** 2026-08-22 按代码现状更新。
> 表结构对应 `database/schema.sql`（PostgreSQL + pgvector）。
> 注意：`detection_results` / `users` / `cascade_logs` / `organizations` / `org_members` / `plugins` / `plugin_findings` 表**不在本 schema 中**，而是由 `frontend/frontend/backend/app.py`（`DB_TABLES_SQL` / `_init_users_table()`）、`cascade_agent.py` 与 `plugin_runtime/` 在运行时 `CREATE TABLE IF NOT EXISTS` 创建。

### 一、设计原则

1. **与三级架构对应**：每层（L1加速器→L2 ML路由→L3 LLM判定）都有对应存储
2. **支持向量检索**：使用 pgvector 插件实现特征向量余弦相似度查询
3. **可连接数据库服务器**：所有连接信息通过环境变量配置，改 `环境变量` 即可切换
4. **兼容现有代码**：`pgvector_client.py` 已有完整实现，只需建表

### 三、完整SQL建表语句

```sql
-- ============================================
-- AIS船舶违规检测系统 - PostgreSQL + pgvector
-- 使用方式: psql -h <host> -U <user> -d <db> -f schema.sql
-- ============================================

-- 启用 pgvector 扩展（如未启用）
CREATE EXTENSION IF NOT EXISTS vector;

-- ============================================
-- 1. 船舶主表（ships）
-- ============================================
CREATE TABLE IF NOT EXISTS ships (
    mmsi VARCHAR(20) PRIMARY KEY,
    ship_name VARCHAR(100),
    ship_type VARCHAR(50),
    length DECIMAL(10,2),
    width DECIMAL(10,2),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- ============================================
-- 2. 原始AIS数据表（raw_ais）
-- ============================================
CREATE TABLE IF NOT EXISTS raw_ais (
    id BIGSERIAL PRIMARY KEY,
    mmsi VARCHAR(20) NOT NULL REFERENCES ships(mmsi),
    timestamp TIMESTAMP NOT NULL,
    lon DECIMAL(10,6) NOT NULL,
    lat DECIMAL(10,6) NOT NULL,
    speed DECIMAL(6,2) DEFAULT 0,
    course DECIMAL(6,2) DEFAULT 0,
    heading DECIMAL(6,2) DEFAULT 0,
    source_file VARCHAR(255),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_raw_ais_mmsi ON raw_ais(mmsi);
CREATE INDEX IF NOT EXISTS idx_raw_ais_time ON raw_ais(timestamp);

-- ============================================
-- 3. 案例主表（cases）—— 三级架构核心
--    含 pgvector 特征向量
--    ⚠️ 维度说明：实际加速器输出为 28 维特征
--       （ais_accelerator/annotator.py FEATURE_NAMES）。
--       本 schema 旧版写 VECTOR(64)（22+42 预留），
--       triage_engine/schema.sql 已同步为 VECTOR(28)。
--       运行时代码（run.py/experiments）做 28→64 补零以兼容模型。
-- ============================================
CREATE TABLE IF NOT EXISTS cases (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    mmsi VARCHAR(20) NOT NULL REFERENCES ships(mmsi),

    -- L1 加速器输出
    source_file VARCHAR(255),
    segment_id VARCHAR(100),
    event_id VARCHAR(100),
    feature_vector VECTOR(64),           -- pgvector 特征向量（见上方维度说明）
    feature_json JSONB,                   -- 特征明细
    annotations JSONB,                    -- 加速器标记列表
    annotation_counts JSONB,              -- 标记统计

    -- L2 ML路由结果
    ml_prediction VARCHAR(50),            -- obvious_issue/has_risk/needs_review/normal
    ml_confidence DECIMAL(5,4),

    -- L3 LLM判定结果
    llm_result JSONB,                     -- LLM完整输出
    llm_agreement BOOLEAN,               -- LLM是否同意ML
    llm_feedback JSONB,                   -- LLM对ML的反馈
    has_violation BOOLEAN,
    violation_type VARCHAR(50),

    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_cases_mmsi ON cases(mmsi);
CREATE INDEX IF NOT EXISTS idx_cases_ml_pred ON cases(ml_prediction);
CREATE INDEX IF NOT EXISTS idx_cases_violation ON cases(has_violation);

-- pgvector 索引（余弦相似度，适合归一化向量）
CREATE INDEX IF NOT EXISTS idx_cases_vector ON cases
    USING ivfflat (feature_vector vector_cosine_ops)
    WITH (lists = 100);

-- ============================================
-- 4. 轨迹序列表（tracks）—— Milvus替代
-- ============================================
CREATE TABLE IF NOT EXISTS tracks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    case_id UUID NOT NULL REFERENCES cases(id) ON DELETE CASCADE,
    mmsi VARCHAR(20) NOT NULL,
    track_json JSONB NOT NULL,            -- 完整轨迹点列表
    segment_id VARCHAR(100),
    metadata JSONB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_tracks_case ON tracks(case_id);
CREATE INDEX IF NOT EXISTS idx_tracks_mmsi ON tracks(mmsi);

-- ============================================
-- 5. 训练集表（training_set）—— 反馈回流
-- ============================================
CREATE TABLE IF NOT EXISTS training_set (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    case_id UUID REFERENCES cases(id) ON DELETE SET NULL,
    feature_vector VECTOR(64),            -- 特征向量（维度说明同 cases）
    label VARCHAR(50) NOT NULL,           -- 目标变量：obvious_issue/has_risk/needs_review/normal
    label_source VARCHAR(20) DEFAULT 'llm',  -- 标签来源：llm/human
    label_confidence DECIMAL(5,4) DEFAULT 1.0,
    sample_weight DECIMAL(6,2) DEFAULT 1.0,  -- 分歧样本权重3.0
    used_in_training BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_training_unused ON training_set(used_in_training)
    WHERE used_in_training = FALSE;

-- ============================================
-- 6. ML反馈记录表（ml_feedback）
-- ============================================
CREATE TABLE IF NOT EXISTS ml_feedback (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    case_id UUID REFERENCES cases(id) ON DELETE SET NULL,
    ml_prediction VARCHAR(50),
    ml_confidence DECIMAL(5,4),
    llm_result_text TEXT,
    llm_confidence DECIMAL(5,4),
    agreement BOOLEAN,                    -- ML与LLM是否一致
    error_type VARCHAR(20),              -- FN/FP/correct
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_ml_feedback_case ON ml_feedback(case_id);
CREATE INDEX IF NOT EXISTS idx_ml_feedback_agree ON ml_feedback(agreement);

-- ============================================
-- 7. 违规记录表（violations）
-- ============================================
CREATE TABLE IF NOT EXISTS violations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    case_id UUID REFERENCES cases(id) ON DELETE SET NULL,
    mmsi VARCHAR(20) NOT NULL REFERENCES ships(mmsi),
    violation_type VARCHAR(50) NOT NULL,
    risk_level VARCHAR(10) DEFAULT 'low',  -- high/mid/low
    violation_desc TEXT,
    evidence JSONB,                        -- 证据链（轨迹URL等）
    ai_suggestion TEXT,                    -- AI建议处置方案
    status VARCHAR(20) DEFAULT 'pending',  -- pending/processing/done
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_violations_mmsi ON violations(mmsi);
CREATE INDEX IF NOT EXISTS idx_violations_status ON violations(status);
CREATE INDEX IF NOT EXISTS idx_violations_type ON violations(violation_type);

-- ============================================
-- 8. 处分文书表（disposal_docs）
-- ============================================
CREATE TABLE IF NOT EXISTS disposal_docs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    violation_id UUID NOT NULL REFERENCES violations(id) ON DELETE CASCADE,
    doc_no VARCHAR(50) NOT NULL UNIQUE,    -- 文书编号
    doc_title VARCHAR(200),
    doc_content TEXT,                       -- 文书全文
    operator_name VARCHAR(50),
    operator_id VARCHAR(50),
    status VARCHAR(20) DEFAULT '草稿',      -- 草稿/已上报/已审核
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX IF NOT EXISTS idx_doc_violation ON disposal_docs(violation_id);
CREATE INDEX IF NOT EXISTS idx_doc_status ON disposal_docs(status);

-- ============================================
-- 9. 法规库（regulations）
-- ============================================
CREATE TABLE IF NOT EXISTS regulations (
    id SERIAL PRIMARY KEY,
    violation_type VARCHAR(50) NOT NULL UNIQUE,
    law_name VARCHAR(200) NOT NULL,
    article VARCHAR(100),
    penalty TEXT,
    description TEXT,
    auto_alert_threshold DECIMAL(5,4) DEFAULT 0.85
);

-- ============================================
-- 10. 视图：待人工复核
-- ============================================
CREATE OR REPLACE VIEW v_pending_review AS
SELECT
    c.id AS case_id,
    c.mmsi,
    c.ml_prediction,
    c.ml_confidence,
    c.llm_result,
    c.has_violation,
    c.violation_type,
    f.error_type,
    f.created_at
FROM cases c
JOIN ml_feedback f ON f.case_id = c.id
WHERE f.agreement = FALSE
ORDER BY f.created_at DESC;
```

### 四、环境变量配置（数据库服务器连接）

| 环境变量 | 默认值 | 说明 |
|---------|--------|------|
| `PG_HOST` | `localhost` | 数据库服务器地址 |
| `PG_PORT` | `5432` | 数据库端口 |
| `PG_DB` | `postgres` | 数据库名 |
| `PG_USER` | `postgres` | 数据库用户名 |
| `PG_PASSWORD` | `wmlwxhn520` | 数据库密码 |

> ⚠️ **默认值来源：** `config.py` 的 `pg_config()`（本项目统一配置中心）。`pgvector_client.py` 构造函数里的 `ais_accelerator` / 空密码是旧默认值，实际运行会被 `config.py` 覆盖。**改配置只改 `config.py` 或环境变量即可，两处一致。**

**修改密码和用户名的方法：**
统一从 `config.py`（`E:\AIS\config.py`）读取，环境变量优先：

```bash
# Windows PowerShell
$env:PG_HOST="你的服务器IP"
$env:PG_PORT="55500"       # 本机 Docker 部署用 55500（55432 在 Hyper-V 排除段，见记忆文件）
$env:PG_DB="postgres"
$env:PG_USER="你的用户名"
$env:PG_PASSWORD="你的密码"
```

### 五、表关系汇总

| 表名 | 对应层级 | 用途 | 核心字段 |
|------|---------|------|---------|
| `ships` | 基础 | 船舶注册信息 | mmsi, type |
| `raw_ais` | L0 | 原始AIS数据 | 位置/速度/航向 |

| `ml_feedback` | 反馈 | ML vs LLM对比 | 一致性与错误类型 |
| `violations` | L3 | 违规记录 | 类型/风险/证据 |
| `disposal_docs` | 上报 | 处分文书 | 编号/内容/状态 |
| `regulations` | 规则 | 法规库 | 违规类型/法条/罚则 |

### 六、与现有代码的对接

1. **`pgvector_client.py`** 已有完整实现，`init_schema()` 方法会执行 `triage_engine/schema.sql` 建表（`cases` / `training_set` / `ml_feedback` 等，特征向量 `VECTOR(28)`）
2. **`database/schema.sql`** 为更完整的建表脚本（含 `ships` / `raw_ais` / `tracks` / `violations` / `disposal_docs` / `regulations` / `v_pending_review` 视图），是本文档所述 E-R 的落点
3. **Flask后端**（`app.py`）数据查询基于运行时创建的表：`detection_results`（检测结果，含 `violation_label` / `violation_event`）、`users`、`cascade_logs`、`organizations`、`org_members` —— 这些不在 `database/schema.sql`
4. **`disposal_docs`（处分文书）**：表已建，但**当前无任何代码写入**（后端无 `/reports` / `POST /violations/:id/disposal` 端点）
5. **主要需要修改的位置**（改数据库连接信息）：
   - `E:\AIS\config.py` 的 `pg_config()`（唯一配置中心，`__init__` 第 44-54 行）
   - 或通过环境变量 `PG_HOST`、`PG_PORT`、`PG_DB`、`PG_USER`、`PG_PASSWORD` 配置
